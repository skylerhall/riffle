Cascade Listen

Patch quantum gates together in any order. Every change cascades through the circuit instantly, and you hear the result: each possible outcome is a note, its probability sets how loud it plays, and its phase sets its color and where it sits from left to right.

Each gate names the wires it takes in. q0, q1… are the starting qubits; a gate's name is its output (name.0, name.1 for two-qubit gates). Order in this list doesn't matter. A wire can feed only one gate, because quantum states can't be copied.

Spectrum

All outcomes play together. Total loudness never changes; probability only moves between notes.
Color = phase. Blue is +, orange is −. Phase can't be measured directly, but it decides which outcomes cancel.
Pan = phase too: + sits right, − sits left.
Right-hand bar = what the machine actually measured.

OpenQASM 3 runs on IBM Quantum and most other hardware and simulators. The cascade.py version runs with the Python prototype. To run your own patch on IBM's machine, save the patch file as my_patch.json in the cascade folder and run python run_ibm.py --patch my_patch.json.
